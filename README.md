# PsyGenie Spring Backend

Spring Boot backend for the PsyGenie platform.

## Tech Stack

- Java 21
- Spring Boot 2.7.18
- Spring Web
- Spring Data JPA
- Spring Security
- JWT (`jjwt`)
- MySQL 8
- Springdoc OpenAPI / Swagger UI
- Maven
